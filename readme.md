## Peta Perjalanan Pelatihan (5 Hari)

Berikut adalah roadmap materi yang akan kita tempuh bersama:

* **Hari 1: Membangun Fondasi**
    * Pengenalan React, setup environment dengan Vite, dan memahami konsep fundamental **Komponen & Props**.

* **Hari 2: Memberi 'Nyawa' pada Aplikasi**
    * Menyelami **React Hooks (`useState`, `useEffect`, `useContext`)** untuk mengelola state, menangani side effects, dan mengambil data dari API.

* **Hari 3: Membangun Dunia Multi-Halaman**
    * Mengimplementasikan **React Router** untuk membuat navigasi antar halaman dan menata ulang seluruh tampilan menggunakan **Tailwind CSS**.

* **Hari 4: Interaksi Penuh dengan Data**
    * Menguasai fungsionalitas **CRUD** (Create, Read, Update, Delete) dan berkomunikasi dengan API secara profesional menggunakan **Axios**.

* **Hari 5: Finalisasi & Demo Day!**
    * Menyelesaikan sentuhan akhir pada Final Project, melakukan *deployment*, dan mempresentasikan hasil karya kamu.
